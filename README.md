# imersao_dados

O foco principal deste trabalho é realizar uma análise exploratória de dados (EDA) para entender a distribuição salarial em diferentes cargos, níveis de senioridade e localizações.

🛠️ Bibliotecas Necessárias :

* Pandas

🚀 Como Rodar o Projeto : 

Ambiente: O projeto foi estruturado para ser executado no Google Colab, mas pode ser rodado em qualquer ambiente que suporte Jupyter Notebooks (.ipynb).
